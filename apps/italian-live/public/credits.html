Italian dictionary

Vocabulary and the dictionary-derived English–Italian spelling matches are adapted from the FreeDict / WikDict for the initial import, subsequently replaced with gender-aware data from English Wiktionary contributors via Kaikki / Wiktextract, October 2026 extraction. These adaptations are licensed under CC BY-SA 4.0.

Changes: select base headwords, exclude some unsuitable entries, add common definite-article forms from dictionary gender and preserve attested plurals, rank by usage frequency, divide vocabulary into study bands and select spelling-similar attested translations. Entries are automatically selected and not each individually reviewed. An overlapping sense does not imply identical usage or shared etymology.
